# PSQ Reburn v0.32 · 魅魔法术说明

使用「魅魔之术：学习」打开法术列表，选择想要学习的法术。学习需要满足表中的魅魔等级、对应魔法学派等级和能量要求；成功学习会消耗表中列出的魅魔能量。

> 学习菜单需要安装并启用 UIExtensions。表中保留菜单里的中文名称；括号中列出学习后法术栏使用的名称。绯夜雷罚出现时才能在菜单中选择。法术效果会受角色、设置和已选兼容组件影响。

## 其他魅魔能力

上述等级以默认的按魅魔等级解锁设置为准；部分能力可在 MCM 中关闭或改为手动选择。

| 游戏中的名称 | 等级 | 作用 |
| --- | ---: | --- |
| 魅魔之术:学习 | 1 | 打开学习菜单，选择并学习上述学派法术。 |
| 魅魔之恋:吸吻 | 3 | 吸取目标生命。 |
| 魅魔之恋:吸精 | 3 | 吸取目标耐力。 |
| 魅魔之恋:飞吻 | 3 | 远程伤害目标，并吸取附近活体的生命、法力和耐力。 |
| 魅魔之术:储物空间 | 3 | 打开个人储物空间；需要启用对应的持续能力设置。 |
| 魅魔之眼：能量感知 | 4 | 标记附近成年存活人形 NPC 的能量状态；再次施放可关闭。需要启用该能力。 |
| 魅魔之术:法转 | 5 | 将魅魔能量转化为法力。 |
| 魅魔之术:召唤商人 | 6 | 召唤魅魔商人；战斗中无法召唤。 |
| 魅魔之术：眷属化 | 7 | 将成年存活的人形 NPC 转化为眷属；需要启用该能力。 |
| 魅魔之术：损伤修复 | 1 | 消耗魅魔能量修复损伤；需要 Apropos 2 和安装器中的对应选项。 |

四大学派的法术通过「学习」获得。其他魅魔能力按其自身条件获得；各级解锁情况请查看[魅魔等级与能力图表](succubus-ranks.md)。
