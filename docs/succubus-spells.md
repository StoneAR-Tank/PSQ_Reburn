# PSQ Reburn v0.32 · 魅魔法术说明

使用「魅魔之术：学习」打开法术列表，选择想要学习的法术。学习需要满足表中的魅魔等级、对应魔法学派等级和能量要求；成功学习会消耗表中列出的魅魔能量。

> 学习菜单需要安装并启用 UIExtensions。表中使用 v0.32 简体中文菜单名称；v0.33 选择其他语言时，名称会有所不同。括号中列出学习后法术栏使用的名称。绯夜雷罚出现时才能在菜单中选择。法术效果会受角色、设置和已选兼容组件影响。

## 持续能力与成长

| 能力 | 默认解锁／条件 | 作用 |
| --- | --- | --- |
| 召唤火元素 | 完成对应使魔契约 | 召唤火元素使魔；再次使用可遣返。 |
| 召唤幽灵马 | 完成对应使魔契约 | 召唤幽灵马使魔；再次使用可遣返。 |
| 召唤幽冥狼 | 完成对应使魔契约 | 召唤幽冥狼使魔；再次使用可遣返。 |
| 生命、法力、耐力、负重强化 | 1级起；持续能力按等级提升 | 默认每级提高各项基础值的 10%。 |
| 格斗、潜行和法术强化 | 1级起；持续能力按等级提升 | 默认每级提高 5%，影响徒手伤害、潜行及法术强度或对应持续时间。 |
| 魔法抗性和口才 | 1级起；持续能力按等级提升 | 默认每级魔法抗性提高 3%，口才增加 5 点。 |
| 技能吸取 | 1级起；MCM 可关闭或调整 | 互动或高潮成功吸取能量时，转移目标的最高技能；默认随魅魔等级增长。 |
| 属性吸取 | 5级起；MCM 可关闭 | 成功互动吸取能量时，转移目标的基础生命、法力或耐力上限；数值随等级提升。当前随从、队友和眷属受到保护。 |
| 种族特性吸取 | 4级起；MCM 可关闭 | 成功互动吸取能量时，随机获得目标种族的一项未拥有特性。 |
| 等级移速加成 | 2级起；MCM 可关闭 | 每升一级，普通形态移速增加 2%，变身形态增加 4%；1级无加成。 |
| 龙吼冷却加成 | 2级起；MCM 可关闭 | 随等级缩短龙吼冷却；1级无加成。 |
| 法术消耗减免 | 1级起；MCM 可关闭 | 随等级降低五大学派的法力消耗；普通形态的减免为变身形态的一半。 |
| 变身属性与护甲 | 1级起；变身期间，MCM 可调整 | 变身期间提高生命、法力、耐力、负重和护甲；数值取决于模式和等级。 |
| 水上行走 | MCM 开启；变身期间 | 变身期间可以在水面行走。 |
| 吸取时灵魂陷阱 | MCM 开启并满足所设条件 | 在符合设置的吸取致死情况下触发灵魂陷阱。 |

四大学派的法术通过「学习」获得。其他魅魔能力按其自身条件获得；各级解锁情况请查看[魅魔等级与能力图表](succubus-ranks.md)。
