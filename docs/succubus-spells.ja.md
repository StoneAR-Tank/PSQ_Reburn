# PSQ Reburn v0.32 · サキュバス魔法ガイド

サキュバスの「学習」能力で魔法一覧を開き、習得したい魔法を選びます。習得には表のサキュバスランク、対応する魔法スキル、エネルギーが必要です。習得に成功すると記載されたサキュバスエネルギーを消費します。

> 学習メニューには UIExtensions の導入と有効化が必要です。表の名前はゲーム内メニューと同じ中国語で、括弧内は習得後の魔法一覧での名前です。绯夜雷罚はメニューに表示された場合に選択できます。効果はキャラクター、設定、互換コンポーネントにより変わります。

## その他のサキュバス能力

ランクはデフォルトのランク別解放設定を基準とします。一部の能力は MCM で無効化や手動選択ができます。

| ゲーム内の名前 | ランク | 効果 |
| --- | ---: | --- |
| 魅魔之术:学习 | 1 | 学習メニューを開き、上記の魔法を選んで習得する。 |
| 魅魔之恋:吸吻 | 3 | 対象の生命力を吸収する。 |
| 魅魔之恋:吸精 | 3 | 対象のスタミナを吸収する。 |
| 魅魔之恋:飞吻 | 3 | 遠距離から攻撃し、周囲の生きた対象の生命力・マジカ・スタミナを吸収する。 |
| 魅魔之术:储物空间 | 3 | 個人収納を開く。対応する常時発動能力の設定が必要。 |
| 魅魔之眼：能量感知 | 4 | 近くの生存する成人型 NPC のエネルギー状態を表示する。再使用で解除。能力を有効にする必要がある。 |
| 魅魔之术:法转 | 5 | サキュバスエネルギーをマジカに変換する。 |
| 魅魔之术:召唤商人 | 6 | サキュバス商人を召喚する。戦闘中は召喚できない。 |
| 魅魔之术：眷属化 | 7 | 生存する成人型 NPC を眷属にする。能力を有効にする必要がある。 |
| 魅魔之术：损伤修复 | 1 | エネルギーを消費して損傷を修復する。Apropos 2 とインストーラーの対応項目が必要。 |

四つの学派の表は「学習」で習得する魔法です。その他の能力には別の解放条件があります。[ランクと能力一覧](succubus-ranks.ja.md)をご覧ください。
