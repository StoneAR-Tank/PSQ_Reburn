# PSQ Reburn v0.32 · サキュバス魔法ガイド

サキュバスの「学習」能力で魔法一覧を開き、習得したい魔法を選びます。習得には表のサキュバスランク、対応する魔法スキル、エネルギーが必要です。習得に成功すると記載されたサキュバスエネルギーを消費します。

> 学習メニューには UIExtensions の導入と有効化が必要です。表の名前はゲーム内メニューと同じ中国語で、括弧内は習得後の魔法一覧での名前です。绯夜雷罚はメニューに表示された場合に選択できます。効果はキャラクター、設定、互換コンポーネントにより変わります。

## 常時発動能力と成長

| 能力 | 既定の解放／条件 | 効果 |
| --- | --- | --- |
| 炎の精霊召喚（召唤火元素） | 対応する使い魔の契約を完了 | 炎の精霊の使い魔を召喚する。再使用で帰還させる。 |
| 幽霊馬召喚（召唤幽灵马） | 対応する使い魔の契約を完了 | 幽霊馬の使い魔を召喚する。再使用で帰還させる。 |
| 幽冥狼召喚（召唤幽冥狼） | 対応する使い魔の契約を完了 | 幽冥狼の使い魔を召喚する。再使用で帰還させる。 |
| 生命力・マジカ・スタミナ・所持重量 | ランク1以降、ランク別の常時能力 | 既定ではランクごとに各基本値の10%を加算する。 |
| 格闘・隠密・魔法強化 | ランク1以降、ランク別の常時能力 | 既定ではランクごとに徒手攻撃、隠密、魔法の強さまたは対応する持続時間が5%上がる。 |
| 魔法耐性と話術 | ランク1以降、ランク別の常時能力 | 既定ではランクごとに魔法耐性が3%、話術が5上がる。 |
| スキル吸収 | ランク1以降、MCM で変更可能 | シーンまたは絶頂でエネルギーを吸収すると、対象の最も高いスキルを移す。既定ではランクに応じて増加する。 |
| 属性吸収 | ランク5以降、MCM で無効化可能 | シーンでエネルギーを吸収すると、対象の生命力・マジカ・スタミナの基本上限を移す。量はランクに応じて増える。現在の従者、仲間、眷属は保護される。 |
| 種族特性の吸収 | ランク4以降、MCM で無効化可能 | シーンでエネルギーを吸収すると、対象種族の未取得特性を一つランダムで得る。 |
| ランク移動速度 | ランク2以降、MCM で無効化可能 | ランク1を超えるごとに通常時の移動速度が2%、変身時が4%上がる。 |
| シャウト再使用時間 | ランク2以降、MCM で無効化可能 | ランクに応じてシャウトの再使用時間を短縮する。ランク1ではボーナスなし。 |
| 魔法消費軽減 | ランク1以降、MCM で無効化可能 | ランクに応じて五大学派のマジカ消費を減らす。通常形態では変身時の半分。 |
| 変身時の属性と防御 | ランク1以降、変身中。MCM で調整可能 | 変身中に生命力、マジカ、スタミナ、所持重量、防御値を高める。数値はモードとランクによる。 |
| 水上歩行 | MCM で有効化、変身中 | 変身中に水面を歩ける。 |
| 吸収時の魂縛 | MCM で有効化し、指定条件を満たす | 設定条件を満たす吸収による死亡時に魂縛が発動する。 |

四つの学派の表は「学習」で習得する魔法です。その他の能力には別の解放条件があります。[ランクと能力一覧](succubus-ranks.ja.md)をご覧ください。
