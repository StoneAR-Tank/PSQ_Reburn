# PSQ Reburn v0.32 · 서큐버스 마법 안내

서큐버스의 「학습」 능력으로 마법 목록을 열고 배우고 싶은 마법을 선택하세요. 표의 서큐버스 등급, 해당 마법 계열 숙련도, 에너지 조건을 충족해야 하며, 배우기에 성공하면 표시된 서큐버스 에너지가 소모됩니다.

> 학습 메뉴를 사용하려면 UIExtensions를 설치하고 활성화해야 합니다. 표에는 v0.32의 중국어 간체 메뉴 이름을 사용했습니다. v0.33에서 다른 언어를 선택하면 이름이 달라집니다. 괄호에는 습득 후 마법 목록의 이름을 표시합니다. 绯夜雷罚는 메뉴에 나타날 때 선택할 수 있습니다. 효과는 캐릭터, 설정 및 선택한 호환 구성 요소에 따라 달라집니다.
