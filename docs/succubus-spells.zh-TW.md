# PSQ Reburn v0.32 · 魅魔法術說明

使用「魅魔之术：学习」開啟法術清單，選擇想學習的法術。學習需要達到表中的魅魔等級、對應魔法學派等級和能量要求；成功學習會消耗表中列出的魅魔能量。

> 學習選單需要安裝並啟用 UIExtensions。表中保留選單顯示的簡體中文名稱；括號內為學會後法術欄的名稱。绯夜雷罚出現在選單中時才能選擇。法術效果會受角色、設定與所選相容組件影響。

## 其他魅魔能力

上述等級以預設的按魅魔等級解鎖設定為準；部分能力可在 MCM 中關閉或改為手動選擇。

| 遊戲中的名稱 | 等級 | 作用 |
| --- | ---: | --- |
| 魅魔之术:学习 | 1 | 開啟學習選單，選擇並學習上述學派法術。 |
| 魅魔之恋:吸吻 | 3 | 吸取目標生命。 |
| 魅魔之恋:吸精 | 3 | 吸取目標耐力。 |
| 魅魔之恋:飞吻 | 3 | 遠程傷害目標，並吸取附近活體的生命、法力和耐力。 |
| 魅魔之术:储物空间 | 3 | 開啟個人儲物空間；需要啟用對應的持續能力設定。 |
| 魅魔之眼：能量感知 | 4 | 標記附近成年存活人形 NPC 的能量狀態；再次施放可關閉。需要啟用此能力。 |
| 魅魔之术:法转 | 5 | 將魅魔能量轉化為法力。 |
| 魅魔之术:召唤商人 | 6 | 召喚魅魔商人；戰鬥中無法召喚。 |
| 魅魔之术：眷属化 | 7 | 將成年存活的人形 NPC 轉化為眷屬；需要啟用此能力。 |
| 魅魔之术：损伤修复 | 1 | 消耗魅魔能量修復損傷；需要 Apropos 2 與安裝器中的對應選項。 |

四大學派的法術透過「學習」取得。其他魅魔能力依各自條件取得；各級解鎖情況請查看[魅魔等級與能力圖表](succubus-ranks.zh-TW.md)。
