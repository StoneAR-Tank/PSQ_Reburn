# PSQ Reburn v0.32 · 魅魔法術說明

使用「魅魔之术：学习」開啟法術清單，選擇想學習的法術。學習需要達到表中的魅魔等級、對應魔法學派等級和能量要求；成功學習會消耗表中列出的魅魔能量。

> 學習選單需要安裝並啟用 UIExtensions。表中使用 v0.32 的簡體中文選單名稱；v0.33 選擇其他語言時，名稱會有所不同。括號內為學會後法術欄的名稱。绯夜雷罚出現在選單中時才能選擇。法術效果會受角色、設定與所選相容組件影響。

| 技能吸取 | 1級起；MCM 可關閉或調整 | 互動或高潮成功吸取能量時，轉移目標的最高技能；預設隨魅魔等級增長。 |

| 種族特性吸取 | 4級起；MCM 可關閉 | 成功互動吸取能量時，隨機獲得目標種族的一項未擁有特性。 |
| 等級移速加成 | 2級起；MCM 可關閉 | 每升一級，普通形態移速增加 2%，變身形態增加 4%；1級無加成。 |
| 龍吼冷卻加成 | 2級起；MCM 可關閉 | 隨等級縮短龍吼冷卻；1級無加成。 |
| 法術消耗減免 | 1級起；MCM 可關閉 | 隨等級降低五大學派的法力消耗；普通形態的減免為變身形態的一半。 |
| 變身屬性與護甲 | 1級起；變身期間，MCM 可調整 | 變身期間提高生命、法力、耐力、負重和護甲；數值取決於模式和等級。 |
| 水上行走 | MCM 開啟；變身期間 | 變身期間可以在水面行走。 |
| 吸取時靈魂陷阱 | MCM 開啟並滿足所設條件 | 在符合設定的吸取致死情況下觸發靈魂陷阱。 |

四大學派的法術透過「學習」取得。其他魅魔能力依各自條件取得；各級解鎖情況請查看[魅魔等級與能力圖表](succubus-ranks.zh-TW.md)。
