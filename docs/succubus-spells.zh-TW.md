# PSQ Reburn v0.32 · 魅魔法術說明

使用「魅魔之術:學習」開啟法術清單，選擇想學習的法術。學習需要達到表中的魅魔等級、對應魔法學派等級和能量要求；成功學習會消耗表中列出的魅魔能量。

> 學習選單需要安裝並啟用 UIExtensions。名稱依 v0.37 遊戲內繁體中文顯示；學會後法術欄名稱不同時列於括號中。† 體檢名稱為說明用翻譯。條件與效果以 v0.32 為準，在新版中可能不同。緋夜雷罰出現在選單中時才能選擇。

## 持續能力與成長

| 能力 | 預設解鎖／條件 | 作用 |
| --- | --- | --- |
| 召喚火元素 | 完成對應使魔契約 | 召喚火元素使魔；再次使用可遣返。 |
| 召喚幽靈馬 | 完成對應使魔契約 | 召喚幽靈馬使魔；再次使用可遣返。 |
| 召喚幽冥狼 | 完成對應使魔契約 | 召喚幽冥狼使魔；再次使用可遣返。 |
| 生命、法力、耐力、負重強化 | 1級起；持續能力按等級提升 | 預設每級提高各項基礎值的 10%。 |
| 格鬥、潛行和法術強化 | 1級起；持續能力按等級提升 | 預設每級提高 5%，影響徒手傷害、潛行及法術強度或對應持續時間。 |
| 魔法抗性和口才 | 1級起；持續能力按等級提升 | 預設每級魔法抗性提高 3%，口才增加 5 點。 |
| 技能吸取 | 1級起；MCM 可關閉或調整 | 互動或高潮成功吸取能量時，轉移目標的最高技能；預設隨魅魔等級增長。 |
| 屬性吸取 | 5級起；MCM 可關閉 | 成功互動吸取能量時，轉移目標的基礎生命、法力或耐力上限；數值隨等級提升。目前的隨從、隊友和眷屬受到保護。 |
| 種族特性吸取 | 4級起；MCM 可關閉 | 成功互動吸取能量時，隨機獲得目標種族的一項未擁有特性。 |
| 等級移速加成 | 2級起；MCM 可關閉 | 每升一級，普通形態移速增加 2%，變身形態增加 4%；1級無加成。 |
| 龍吼冷卻加成 | 2級起；MCM 可關閉 | 隨等級縮短龍吼冷卻；1級無加成。 |
| 法術消耗減免 | 1級起；MCM 可關閉 | 隨等級降低五大學派的法力消耗；普通形態的減免為變身形態的一半。 |
| 變身屬性與護甲 | 1級起；變身期間，MCM 可調整 | 變身期間提高生命、法力、耐力、負重和護甲；數值取決於模式和等級。 |
| 水上行走 | MCM 開啟；變身期間 | 變身期間可以在水面行走。 |
| 吸取時靈魂陷阱 | MCM 開啟並滿足所設條件 | 在符合設定的吸取致死情況下觸發靈魂陷阱。 |

四大學派的法術透過「學習」取得。其他魅魔能力依各自條件取得；各級解鎖情況請查看[魅魔等級與能力圖表](succubus-ranks.zh-TW.md)。
