# PSQ Reburn v0.36

## 變身換裝加速

預設關閉，沿用原本的換裝方式。勾選後，變身時穿衣及解除變身時換回原裝備都會更快。兩種方式都能使用魅魔面板。

已有存檔建議從變身前的存檔繼續。若要切換方式，請先關閉遊戲，在 MO2 重新安裝本模組並選擇「取代」，再啟動遊戲。

在第一頁選擇語言。後續安裝選項、MCM、魅魔面板、法術與物品說明都會使用所選語言。若要切換語言，請在 MO2 重新安裝後重啟遊戲。

請安裝符合遊戲版本的 SKSE64、Address Library，以及 SkyUI、PapyrusUtil、SexLab、Heels Sound。SexLab SE 與 P+ 擇一使用。

變身服裝需要另行安裝對應的原作服裝。在 BodySlide 選擇對應 3BA 或標準 UBE 預設，勾選「Build Morphs」並建置 PSQ 服裝。Body Change 選項適用於獨立安裝的 Body Change NG 1.3.8。

選擇符合遊戲解析度的全螢幕版面，進入遊戲後使用「魅魔面板」開啟。

4K 螢幕請選擇 3840 × 2160（4K UHD）。

換裝加速現在會在外觀處理卡住時嘗試從目前步驟恢復。 使用 PSQ 預設的 3BA 變身服裝。如果角色使用 3BA，選這一項即可。
