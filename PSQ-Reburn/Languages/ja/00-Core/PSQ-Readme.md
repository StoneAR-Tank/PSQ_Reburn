# PSQ Reburn v0.33

はじめに言語を選んでください。後続のインストール画面、MCM、サキュバスパネル、魔法やアイテムの表示に適用されます。言語を変更する場合は MO2 で再インストールし、ゲームを再起動してください。

ゲームのバージョンに合った SKSE64、Address Library、SkyUI、PapyrusUtil、SexLab、Heels Sound が必要です。SexLab SE と P+ はどちらか一方を使用してください。

変身衣装を使うには対応する元の衣装を別途導入します。BodySlide で 3BA または標準 UBE に合ったプリセットを選び、「Build Morphs」を有効にして PSQ の衣装をビルドしてください。Body Change 連携は別途導入した Body Change NG 1.3.8 用です。

解像度に合ったレイアウトを一つ選び、ゲーム内で「サキュバスパネル」を使用して開いてください。
