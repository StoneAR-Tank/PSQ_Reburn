# PSQ Reburn v0.35

## Faster outfit changes

Leave unchecked to use the original outfit changes (default). Enable for faster dressing when transforming and faster gear restoration when changing back. The Succubus Panel works with either method.

For an existing character, load a save from before the transformation. To switch methods, close the game, reinstall this package in MO2, choose Replace, then launch the game again.

Choose your language on the first installer page. It applies to the remaining pages, MCM, the Succubus Panel, and PSQ spell and item text. To switch later, reinstall the mod in MO2 and restart the game.

Install SKSE64 and Address Library for your game version, plus SkyUI, PapyrusUtil, SexLab, and Heels Sound. Choose either SexLab SE or P+.

For transformation outfits, install the original outfits separately. In BodySlide, select the matching 3BA or standard UBE preset, enable Build Morphs, and build the PSQ outfits. The optional Body Change interface is for a separate installation of Body Change NG 1.3.8.

Select one fullscreen layout for your resolution. In the game, use Succubus Panel to open it.

For a 4K UHD game resolution, select 3840 × 2160.

Faster outfit changes now try to recover from the current step if an appearance change stalls. Use the default 3BA transformation outfits. Choose this for a 3BA character.
