# PSQ cloth UBE patch — DX 作者转换接入

使用已有的 DX Succubus (Mazken) Armor (UBE) 转换，来源：https://www.nexusmods.com/skyrimspecialedition/mods/116652 。没有自行重新拟合、转换身形或重绘权重。原转换的 ShapeData NIF/OSD 逐文件哈希保持一致；BodySlide 按显式零预设生成游戏模型和变形。八个部件的源顶点与生成顶点误差均小于0.0001，拓扑保持一致。

配套原服装是本机的 DX Succubus Armor 简中轻甲 ESPFE。重映射十条原服装护甲覆盖，保留原护甲属性和普通种族模型；增加六件仅供 PSQ 的不可在装备栏选择的 UBE 变身物品。英文插件名为 PSQ UBE DX.esp，ESL 标记。

六部分：上衣＝胸甲＋项链＋肩饰＋裙片＋耳饰；靴子＝高跟鞋；手套＝手套；角饰＝角饰；尾巴＝尾巴；翅膀＝翅膀。使用作者的独立模型/分区，没有把八个模型合成一个，也没有借其他套装部件。

PSQ 根据玩家实际 UBE 种族和补丁是否存在选择资源。普通种族继续使用原 CBBE 配置；换回普通种族时重新解析对应 DX 部件。其他未转换的服装仍受 UBE 保护，身体、皮肤、纹身和 TRX 的保护规则不变。兼容页面增加“DX魅魔 UBE 服装适配”检测。

在“变换”页面将所需部位设为 DX 魅魔；翅膀也可独立选择 DX。旧档原本选中 DX 的配置会在建立下一次变身换装计划时解析为对应种族版本。不要求普通种族使用本补丁。

安装位置：这个独立模组 PSQ cloth UBE patch 提供服装资源和插件，PSQ 本体提供兼容脚本。没有修改独立 DX、UBE 或 Body Change NG 目录。原作者转换的插件针对未压缩原版，不能与本补丁叠加启用。本包不收录 BurgerNecoco 或自制 Helena 拟合。

已完成：旧 SexLab / P+ 2.19 双编译、函数级保留校验、作者源数据和生成顶点/拓扑对照、全部模型路径和 UBE 种族引用检查。未完成：游戏内变身/退出、极端身形、物理与第一人称实测。没有声称九套服装均已完成转换。
