# 变身时隐藏原有附加装备（2026-11-02）

基于PSQ-Reburn-v0.27修订45，当前修订46。新增PSQ专属PSQAppearance.dll 1.0.0.1/API1；只安装到PSQ目录，不修改独立Body Change NG、服装或其他模组。该DLL独立执行可见性控制，不依赖Body Change接口。需要SKSE64与匹配当前游戏版本的Address Library；缺少地址库／接口时不启用隐藏并回退原卸装流程。

MCM→变换→“隐藏原有附加装备”，在变身皮肤及肤色选项附近，默认开启。仍穿着的原有附加装备只隐藏模型，其护甲、附魔及其他装备效果继续生效，不转入储物空间。与变身衣服冲突的槽位仍由正常装备动作替换，原物品完整保留并在退出时恢复。帽子、影响发型显示的头部槽位、包含身体／手／脚皮肤的物品继续使用原卸装规则。不会强行让同槽位两件护甲同时装备。

原皮肤、变身部件、GT/UBE受保护物品、当前PSQ管理的TRX部件不作为隐藏目标；共用模型或父节点包含保护对象时跳过。对照角色实际第一／第三人称Biped部件，避免靠通用节点名误隐藏身体。预先已被隐藏的节点不由PSQ接管。仅在主线程任务内读写可见性；过期任务丢弃。

退出／卸载准备时恢复PSQ修改的可见性；新游戏／读档前后清理原生记录。变身状态下每0.75秒重新核对原装备模型，以覆盖换镜头、模型重建、读档后的重新挂载；普通形态不持续轮询。结束、关闭选项、换档或卸载时旧任务停止。关闭选项会恢复可见，下一次变身按原卸下流程处理；已经被槽位替换卸下的装备不会因此强行穿回。

请注意：隐藏不等于停止物理运算，也不改变其他模组对“已装备”的判断。它保留装备加成，可能改变相对于旧卸装方式的数值表现。没有修改任何模型、材质、插件护甲属性或第三方目录。

验证：旧SexLab和P+2.19编译通过；652项最终字节码离线检查及623项生产可见性策略检查通过，含原换装／皮肤／UBE回归、隐藏与回退、头部／身体保护、菜单、读档任务代次、重复引用、已有隐藏标记、模型重建、反复恢复与引用释放。游戏内可见性、物理表现和耗时改善尚未验收。重启游戏后用多配件装备测试变身、切镜头、读档、退出，确认原配件恢复。

DLL源码、CommonLib源码、许可证和测试见Docs/PSQAppearance-1.0.0.1-Source.zip。旧版Body Change DLL完全不变。
