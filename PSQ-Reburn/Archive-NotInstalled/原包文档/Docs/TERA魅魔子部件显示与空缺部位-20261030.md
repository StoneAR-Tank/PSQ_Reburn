# TERA魅魔子部件显示与空缺部位

本次对应编号100、TeraSuccubusArmor.esp的TERA魅魔，不改编号5的TERA魅魔2。

保留六部分选择界面：上衣包含胸衣、项圈、吊袜带、内裤；靴子包含靴子、长袜；手套为原作护手；尾巴为原作尾巴。原作没有角饰、翅膀，这两个部位留空，不再借用其他套装。相关借用选项、两个BS工程及八个专用模型/变形文件移除，旧FormID保留为空记录，旧存档中使用它们的配置会关闭；手动选的其他角饰、翅膀保留。

原适配将胸衣、项圈、吊袜带、内裤都映射为32，靴子和长袜都映射为37。改为每个子部件使用独立槽位：胸衣32、项圈35、吊袜带49、内裤52、靴子37、长袜46。上衣/靴子的装备记录覆盖所有子部件槽位，仍分别只穿一件PSQ组合装备；不增加独立穿戴按钮。模型、BS源模型、装备/模型记录的槽位同步，顶点、蒙皮、形状、变形文件不改。女性第一/第三人称模型路径也直接写入记录，减少对运行时补全空路径的依赖。原作仍是CBBE，未在本次转换为3BA。

上衣占52时，TRX联动不会把它记作待恢复的普通衣物，避免退出或关闭扶她时误回穿变身上衣。穿衣隐藏仍保留。

两框架编译通过；326项离线字节码检查通过，其中192项为上一轮FUTA穿衣隐藏检查。检查组合装备、子部件与NIF槽位一致；非目标插件记录、其他脚本函数、FormID和主文件列表保持。所有修改只在PSQ目录；独立服装、TRX、Body Change不改。已备份，尚未进行游戏内显示验收。

测试：重启游戏后退出再进入变身，选择TERA魅魔上衣和靴子，确认项圈、吊袜带、内裤、长袜显示；原来选择TERA魅魔角饰/翅膀的配置应关闭。没有重新Build的必要；以后Build时使用PSQ更新后的适配工程，避免旧的外部输出覆盖新版分区。
