# FUTA穿衣自动隐藏

PSQ管理的TRX部件在穿戴躯干（32）或下身（49、52）装备时隐藏，脱下对应装备后恢复。TRX部件自身不算衣服；只有帽子、手套、靴子时不触发。使用槽位判断，透明或开放式服装只要占用上述槽位也会隐藏。

隐藏采用临时脱下PSQ管理的TRX部件，保留启用状态、选择、大小、皮肤、加成与性别判定；不会反复添加物品。隐藏期间选择新的部件或大小，脱衣后应用。52槽被其他装备占用时保留其他装备；关闭功能不会强行挤掉当前下身装备。仅回收PSQ临时添加的一件TRX，保留玩家原有数量。

玩家穿脱装备事件会触发合并后的延迟处理；现有读档、变身完成、模型更新和BCNG模型就绪流程也会检查。NPC模型更新沿用同一处理。变身或恢复忙碌时等待，最多有限重试，不新增持续扫描。TRX自身穿脱事件只在状态不符时补充处理，状态稳定不再回放。隐藏期间停止皮肤和节点重试，恢复后沿用原来的皮肤和大小流程。

两种SexLab接口编译通过，192项最终字节码离线分支检查通过。只替换主脚本7个函数与玩家别名的2个装备事件，其他538个主脚本函数及16个别名函数逐字节保留。增加4个辅助函数，无新增持久脚本字段、插件记录、DLL或资源。独立TRX和Body Change目录不改。实际游戏内显示仍待验证，需重启游戏加载新版脚本。
