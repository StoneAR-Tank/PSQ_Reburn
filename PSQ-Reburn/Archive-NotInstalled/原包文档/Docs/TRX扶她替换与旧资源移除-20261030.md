# TRX 扶她适配与旧资源移除

PSQ 的扶她外观改为直接引用可选插件 SOS - TRX - Futanari Addon.esp 的可装备部件。菜单提供 TRX 普通、TRX 轻甲、TRX 重甲。支持本机生效的 TRX-扶她 版本（0x036C0D／0x036C0B／0x036C09）及另一份原始编号版本（0x000842／0x000840／0x00083E）。不新增硬前置；未安装 TRX 或缺少模型时显示中文提示且不生成空装备。TRX 自身的 SOS 前置仍需正常安装。

引用原生装备的整套 ArmorAddon、种族贴图和模型，不复制 TRX 的贴图或模型进 PSQ，不修改 TRX 两份原目录。实际生效的 TRX-扶她 包含按种族区分的原生 ArmorAddon，三个装备共29个不同模型／贴图依赖已核验。形状与物理以用户当前 TRX 模型及 BodySlide 构建结果为准；本次不重新构建 TRX。

删除 PSQ 的 meshes/psq/Schlong、textures/psq/schlong 以及仅供旧D款使用的4张 vampirelord_penis 贴图，共26文件、49,344,025字节。核查剩余PSQ模型，没有其他模型依赖这批贴图。20条旧 ARMO／ARMA／TXST 记录保留编号但移除外观、模型、贴图与部位占用，供旧存档识别清理，不再提供旧资源。ESM其他记录与硬前置列表保持。

玩家创建法术、进入／退出变身、NPC创建法术和NPC变身路径均使用新接口。普通形态与魅魔形态可分别选TRX款式。每个角色独立保存52槽原装备、当前PSQ管理的TRX物品及是否由PSQ临时添加；关闭时只回收临时添加的一件，保留个人库存中的原有TRX物品并恢复原装备。穿戴失败撤回新物品、恢复上一件，避免把失败当成功。SexLab性别仅在选项启用时调整，记录由PSQ取得的控制；关闭时不清除原本已存在的外部男性判定。扶她加成与原有等级解锁保留。

旧存档载入既有清理入口会清除玩家旧A～E物品并按当前形态尝试接入TRX。未安装TRX时清除旧PSQ状态、加成和可识别的旧性别覆盖，尝试恢复原52槽物品。旧NPC在下次创建／变身操作时清理其旧物品，不扫描世界所有NPC。无法重建旧脚本曾覆盖丢失的NPC装备备份，因此不猜测其他角色的旧原装备。

双框架（旧SexLab、P+2.19）编译通过，最终脚本一致；286项实际最终字节码离线流程检查通过，覆盖两套TRX编号、三款、玩家／NPC、重复调用、原有物品保护、变身转换、穿戴失败回退、旧存档迁移及未安装TRX。只替换必要函数，510个其他主脚本函数和322个其他菜单函数逐字节保留。游戏内显示、物理和实际SOS配合仍待验证。

测试：重启后，在PSQ选择TRX普通，使用创建法术测试开／关；随后测试变身进入与退出，以及退出后原52槽装备和库存数量是否恢复。外观不贴身时在TRX的BodySlide项目中按身体预设构建并勾选建立变形。
