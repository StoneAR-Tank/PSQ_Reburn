# 变身服装按身形隔离

- UBE 角色的服装菜单只提供已安装、模型存在的 UBE 转换部件；没有转换时不回退到 3BA。
- 3BA 角色只选择原有 3BA 部件；存档残留的 UBE 选择会按同一套装/部位解析为 3BA 部件。
- UBE 服装包使用独立的隐藏装备记录，不再覆盖/混入 3BA 装备记录。
- 保留六部位独立切换。缺失的角饰、翅膀保持空缺；独立动态翅膀作为不依赖身体模型的附件保留。
- 菜单打开后若种族或身体类型变化，旧菜单选择会被拒绝，需要重新打开。
- 装备计划记录身体类型，最终装备入口再次检查，防止使用旧缓存穿上错误身形的装备。
- 本体提供统一接口，UBE 服装包不再携带旧版同名脚本，避免以后覆盖本体更新。

无需清档。正常退出变身后保存，退出游戏安装，再测试变身/退出变身。
新版 UBE 服装包必须配合此次本体接口更新。原服装、UBE、Body Change NG、独立 WingFlight 均不修改。
旧 SexLab 与 P+ 2.19 编译和 2,508 项编译后路由测试通过；游戏运行效果仍待实测。
