# PSQ Reburn v0.38

## 变身换装加速

默认关闭，使用原来的换装方式。勾选后，变身穿衣和退出时换回原装备会更快。两种方式都能使用魅魔面板。

已有存档建议从变身前的存档继续。切换换装方式时，先退出游戏，在 MO2 重新安装本包并选择「替换」，再启动游戏。

先选语言，再到「本体附加功能」选择换装方式。语言也用于游戏中的魅魔面板、菜单、法术和物品。

请安装与游戏版本匹配的 SKSE64 和 Address Library，并安装 SkyUI、PapyrusUtil、SexLab 和 Heels Sound。SexLab SE 与 P+ 任选其一。

变身服装需要另装对应的原作服装。在 BodySlide 选择与你的 3BA 或标准 UBE 身形匹配的预设，勾选「建立变形」，构建 PSQ 服装。Body Change 联动适用于独立安装的 Body Change NG 1.3.8。

选择与你的游戏分辨率相符的全屏布局，进游戏后使用「魅魔面板」打开。

4K 屏幕请选择 3840 × 2160（4K UHD）。

换装加速现在会在外观处理卡住时尝试从当前步骤恢复。 使用 PSQ 默认的 3BA 变身服装。如果角色使用 3BA，选这一项即可。
