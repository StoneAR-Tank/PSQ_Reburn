# FUTA统一页面与大小调节

全部FUTA设置集中到“身体形态变化”：普通／魅魔形态TRX部件、BCNG皮肤、变身创建开关、SexLab性别判定、扶她加成、创建法术、创建热键与阴茎／阴囊调节热键。相关条目从其他设置、变换、魔法与特性、热键设置移除，不再重复显示。原有魅魔身高和臀部控制保留。法术自动解锁与手动管理权限沿用原规则。

普通形态新增阴茎／阴囊大小倍率，默认1倍。魅魔形态保留原独立大小开关和数值；关闭独立选项时沿用普通形态倍率，确认魅魔倍率会自动开启对应独立控制。范围0.25～3倍，步长0.05，默认重置为1倍。确认后关闭菜单刷新，没穿TRX时先保存，之后创建或变身时应用。

使用当前生效TRX模型已有的 NPC Genitals01 [Gen01] 和 NPC GenitalsScrotum [GenScrot] 骨骼，以NiOverride独立 PSQ_TRXFuta 键写入一／三人称对应节点。1倍不额外放大，SOS自身大小仍可能叠加。只清理本功能旧PSQ键和自己的新键，不修改SOS或其他模组的缩放。重复相同设置不重写节点、不累计放大；关闭、退出和读档后的刷新使用同一流程。模型未就绪时有限重试，BCNG原有模型就绪事件也会触发同步，不新增持续扫描。

当前SexLab目标NPC的变身扶她开关、阴茎／阴囊倍率也移到本页，先在SexLab选择目标。NPC倍率存于该NPC，不再误作用到玩家；没有独立NPC倍率时继承相应形态的通用设置。修正NPC进入扶她路径前仅检查玩家总开关的问题，由目标自己的开关决定是否启用。与其他NPC身体或皮肤逻辑无关。

静态检查：当前生效TRX模型包含两个目标骨骼；旧SexLab与P+2.19编译通过；140项最终字节码离线分支检查通过，覆盖页面唯一入口、普通／魅魔切换、倍率边界、复位、首次／重复应用、外部SOS层保留、节点缺失与就绪、事件过期、第一人称及NPC隔离。529个其他主脚本函数、339个其他菜单函数、4个其他NPC效果函数逐字节保留。TRX、BCNG、模型、贴图、DLL及MO2配置均不改。游戏内视觉与物理表现仍待测试。
