# 多部件变身与场景负载修订（修订50）

## 已安装改动

本次只更新 PSQ。退出时将占身体、手、脚槽位的原装备放在第一阶段，按实际槽位识别，不依赖旧存档中可能缺失的主装备字段。主装备完成有限次数重试后才释放配件隐藏并处理其余装备；若主装备仍被外来装备阻挡，保留未恢复记录，不能强行挤掉外来装备或清空记录。已经穿着的隐藏配件不重复装备。最终操作结束仍有安全解除隐藏，避免失败后永久不可见。

修正两个确定的提前显示入口：退出刚把变身状态设为关闭时，后台隐藏维护不再提前解除隐藏；装备恢复函数也不再在开头解除隐藏。额外修正旧维护任务在退出、读档或用户关闭隐藏之后才完成，导致重新隐藏的问题。保留卸载与显式关闭隐藏的恢复通道。

现有 PSQAppearance 辅助组件升级到1.0.0.2/API2。将玩家身形类型、装备模型类型的多次脚本读取合并为只读查询，每次读取当前数据，不缓存跨种族状态。保留前16个女性第三人称模型、路径前缀、大小写和皮肤选择规则；NPC、特殊玩家模板、特殊轻插件版本或旧接口继续使用完整旧检查。仍严格区分 UBE 与3BA；没有新增装备搬运、库存重造或后台轮询。

修复补满过程中的 None→Float[] 转换错误，保留三项上限稳定性、补满确认、操作归属和有限次数重试。也修正身形预设目录和旧TERA借用部件清理中的相同数组判断问题。未提高或降低加成、没有增加无限补满。
