# Body Change NG 扶她皮肤管理

PSQ继续管理TRX部件的创建、普通／魅魔形态装备、等级解锁、加成和SexLab性别判定；Body Change NG管理扶她贴图应用。TRX原模型、物理、种族ArmorAddon和原贴图仍来自独立TRX模组。所有接口文件及DLL覆盖均在PSQ中，独立TRX和Body Change NG目录不改。

“其他设置”的扶她设置区域新增普通形态扶她皮肤、魅魔形态扶她皮肤及接口状态。默认均为“跟随 Body Change”，保留BCNG现有选择；“TRX装备默认贴图”临时使用原TRX贴图；其他选项为BCNG目录中的兼容TRX皮肤包。两个形态可以分别指定。确认后关闭菜单应用；改变不活跃形态的选项只保存，不影响当前形态。NPC创建采用普通形态设置，NPC变身采用魅魔形态设置，角色之间的备份互不共用。

从本机当前实际生效的TRX贴图原样导入5张DDS（44,740,068字节），位于 Futanari/TRX 默认皮肤/Textures/[TRX] Futa addon/Regular/Default。包含原色、法线、辅助与可选湿法线，未重绘或转换UV。此目录供BCNG扫描；不重建TRX模型，不复制TRX插件，也不恢复此前删除的PSQ旧扶她资源。该包使用人类默认图集，PSQ接口只向匹配的人类/CBBE TRX路线提供皮肤目录，兽族保留TRX原种族贴图。

BCNG接口扩展为1.3.7.3/API3，保留原API1/2的身形和装备变形刷新接口。脚本先核对确切DLL版本，避免调用未注册的原生函数。新增接口支持目录查询、选择状态查询、请求应用和仅在仍持有控制权时恢复。原来自动／手动／默认／未管理状态均能恢复，退出变身按普通形态设置处理；关闭扶她时恢复PSQ接管前的BCNG选择。若用户在BCNG界面主动改为另一皮肤，PSQ停止自动覆盖，退出时也不撤销该新选择；用户在PSQ重选皮肤可重新接管。

装备完成后使用独立事件请求刷新；关闭菜单后执行，同一角色只保留最新请求，过期读档回调取消。暂时未找到TRX模型时最多16次短暂等待。BCNG在原有装备／模型就绪事件中通知PSQ，待真实TRX节点出现后可重试；已持有正确选择时不重复请求，不新增持续扫描或遍历全世界NPC。普通身体、身体皮肤、淫纹、覆盖层及装备物品的归属不由此接口改写。原生返回“已排队”仅表示接受请求，不当作画面已完成。

备份和读档：BCNG选择继续由BCNG的.skse同存档数据保存，PSQ接管前选择与形态设置由PapyrusUtil保存。保留配对的.ess与.skse。只保存皮肤选择，不修改TRX贴图源文件。

验证：旧SexLab与P+2.19编译通过；462项实际最终字节码离线检查通过，包含原286项TRX装备流程；66项原生策略检查通过。覆盖完整普通→魅魔→普通→关闭恢复、外部手动接管、默认／自动／未管理状态、两角色隔离、旧DLL降级保护、过期菜单和事件、模型就绪重试及重复事件不产生刷新循环。518个其他主脚本函数、330个其他菜单函数逐字节保留。原生DLL Release编译、导出和版本检查通过，仍未验证游戏画面、真实遮盖切换和GPU材质表现。

使用：重启游戏，先创建TRX部件或启用变身扶她。在PSQ选择普通／魅魔扶她皮肤后关闭菜单测试；也可按F7打开BCNG，在扶她皮肤页单击预览、双击确认。新增默认包已就位，无须再复制旧PSQ贴图。想完全交给BCNG界面选择时，将PSQ两项都设为“跟随 Body Change”。
