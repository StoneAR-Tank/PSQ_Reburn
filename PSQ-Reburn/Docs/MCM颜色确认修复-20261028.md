# MCM颜色确认事件修复（2026-10-28）

现象：发色、肤色可以打开颜色窗口，但确认后不保存。

原因：菜单已有OnColorOpenST及HandleAppearanceOnColorAcceptST处理函数，却缺少默认状态的OnColorAcceptST确认入口，落入SkyUI父脚本的空处理。修订补回入口，按现有外观编辑保护调用颜色写入与菜单刷新，并释放当前编辑锁；操作期间菜单目标已变化时取消写入，旧操作不释放新操作的锁。

发色、肤色、八个能量条颜色和NPC肤色共用此入口。纹身发光颜色保留自己的事件；原有317个菜单函数逐字节不变，主脚本、装备和服装适配不改动。

旧SexLab/P+编译通过，258个实际PEX指令测试验证保存、刷新、锁拒绝、菜单目标变化、操作取消和独立纹身事件。尚未进行游戏验证。

安装后请正常退出并重新启动游戏，再选择发色/肤色、确认，重新打开菜单检查数值。无需清理存档或重置MCM。保存设置与角色当场显示是不同步骤：非变身时只保存变身颜色；皮肤仍受外观保护策略约束。
