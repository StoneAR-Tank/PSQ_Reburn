# TERA魅魔BS刷新

按当前BodySlide配置，使用“归零滑条”并开启“建立变形”，单独构建TERA魅魔的胸衣、项圈、吊袜带、内裤、靴子、长袜和护手七个PSQ适配工程。生成14个重量模型和7个TRI，输出安装到PSQ。尾巴为静态原作模型，本次不重建；角饰和翅膀继续留空。未重建其他服装或改动全局BS配置。

构建中发现适配工程曾错误过滤胸衣内部身体的BaseShapeHR滑条数据；若直接Build，身体89个变形会丢失。恢复原作对应90条身体数据引用，将其依赖的实际生效CBBE Body.osd复制到PSQ自己的适配数据目录，并修正工程引用，保证以后Build仍保留身体变形。该项不改独立服装或CBBE原目录。

核验7个工程均产生0/1重量模型和TRI，原有全部形状及变形名保留，身体89个变形存在，BODYTRI路径正确，所有分区继续匹配上一轮独立槽位。模型仍按原作CBBE类型构建，本次不是3BA转换。隔离调用已安装BodySlide，不改动原工具、MO2配置或独立服装目录。已备份；游戏内穿戴效果待确认。
