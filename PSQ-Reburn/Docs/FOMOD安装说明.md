# PSQ Reburn v0.41 安装说明

PSQ Reburn 是《上古卷轴 V：天际特别版》的魅魔系统模组。详细功能、前置需求、服装下载、排序建议和致谢，请查看 [项目主页](https://github.com/StoneAR-Tank/PSQ_Reburn)。

## 安装与升级

1. 升级前，结束互动，退出变身和飞行，在安全地点保存游戏并备份存档。
2. 安装游戏对应版本的 SKSE64、Address Library、SkyUI、PapyrusUtil、Heels Sound，以及 SexLab SE 或 P+。欲望相关功能需要另行安装相应模组。
3. 在 MO2 中安装 PSQ Reburn，停用旧版 PSQ 和旧的 PSQ 累积补丁。在安装器中选择游戏语言、魅魔面板、身形、服装和需要的兼容组件。
4. 想使用的独立服装、飞行和其他可选模组需要另外安装；服装的下载位置和各项功能的前置需求可在项目主页查看。信浓和 TERA（Harry）的 3BA 服装使用已安装的原版 BodySlide 工程；UBE 工程可在安装器中选择。使用 WeiLong 服装时，还需要其原版服装及 WeiLong.esp。TDF 兼容组件仅供已安装 TDF Enhanced Prostitution 的玩家选择。
5. 如使用 BodySlide，请选择与身体一致的预设，为所需的 PSQ 服装生成身形并勾选 Build Morphs。旧的 PSQ 专用服装输出如果覆盖新版，请重新生成。
6. 按项目主页的建议检查模组排序，重新启动游戏，在 PSQ 的 MCM 菜单中检查设置后即可使用。

安装器提供简体中文、英文、日文和繁体中文的游戏文字。更换语言时，请在 MO2 中重新安装并重启游戏。
