# 龙之公主及TERA 9DM适配

对应独立原作：Dragon Princess - 简中 3BF（BBP_Dragon_Princess.esp）；TERA Succubus 9DM - 简中 3BA（TR9DmRxSS_HR.esp）。两者分别接入原Set03龙之公主、Set05 TERA魅魔。Harry TERA“TERA魅魔装甲”保持独立。

安装原作、启用插件后，兼容页显示状态，变换页可按上衣、靴子、手套、角饰、尾巴、翅膀六部分选择。缺少原插件、必要装备记录或PSQ适配资源时拒绝新选。保留原有FormID、菜单编号与旧存档的模型回退。本次保留三套旧服装资源包，未删除其中资产。

PSQ内保留已有的六件组合与3BA适配，包括原作未独立提供的补全部件。Dragon Princess原包标为3BF，不将它描述为完成3BA转换的独立原作；PSQ变身使用自身已有的身形适配版本。原作文件夹及ESP均不改动。

同时修正龙之公主8个法线贴图文件名；胸甲一处原作未提供对应法线，清除该缺失引用并保留原色贴图。修订仅作用于PSQ模型及其BS源文件。

TERA的模型及贴图使用BSA封装，已读取目录验证，检测不会要求原作解包。非原作提供的补全部件依赖放在PSQ内，两个适配组不再依赖旧服装资源包。服装仍需实际配套的前置及原作资源。

BodySlide新增“PSQ External DragonPrincess Adapter”“PSQ External TERA9DM Adapter”两个组，共12个工程。与身体使用一致预设，勾选建立变形；已有旧BS输出不得覆盖本次模型修正。六部分的显式穿戴分区已统一，保持几何、UV和骨骼权重。

MO2中PSQ覆盖两个原作；仅移动这两个原作条目的覆盖顺序，其他mod顺序及已有插件相对顺序不动；两项新插件若未登记则追加并启用。所有兼容文件仅放在PSQ内，不增加额外ESP。

检查36个NIF、12个BS工程、变形顶点索引、贴图、物理对象及原作装备记录；旧SexLab/P+编译通过，822项PEX指令回归检查通过。502个无关主脚本函数、316个无关菜单函数保持原字节，包含此前颜色确认、其他服装与菜单修改。游戏运行表现待测试。
