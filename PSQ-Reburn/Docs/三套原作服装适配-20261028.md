# 三套原作服装与PSQ六部件适配（2026-10-28）

## 统一条目名称

英文名 - 中文名 - 汉化状态 - 支持身形：
- SucubusSister Shinano - 信浓魅魔姐妹 - 简中 - 3BA SMP
- DX Succubus Armor - DX魅魔装甲 - 简中 - 3BA SMP（轻甲 ESPFE）
- Helena Succubus - 海伦娜魅魔 - 简中 - 3BA SMP

三套原作保留在“PSQ服装”分组。PSQ优先级高于该分组，负责全部兼容覆盖；原作的ESP文件名、资源目录和现有FormID不重命名。原作目录只修改MO2条目元数据，兼容内容均放PSQ。

## PSQ变身：始终只有六部分

上衣、靴子、手套、角饰、尾巴、翅膀。原作的额外配件按现有PSQ搭配合并进相应部分，六部分仍可独立选择与混搭。保留PSQ原有装备记录、隐藏装备逻辑及退出恢复。没有把原作10件或38件直接塞进变身流程。

DX上衣组合含护符、肩甲及短裙；海伦娜上衣含项圈，翼独立；信浓上衣沿用body1+toy+skirt1+Strip1+upper1，配件独立为其他五部分。兼容页分别显示三套原作检测状态。三套均改为原作专用：缺少原作时不可新选；旧保存配置临时使用Set04安全模型。

## 独立穿戴的补全

| 套装 | 原作与PSQ的差异 | 当前配置 |
| --- | --- | --- |
| 信浓 | 原作38件、四色，PSQ六件为固定合并搭配 | 保留原作四色/34个BS项目、SMP修正及PSQ六件适配；没有删掉原作额外配件 |
| DX | 原作UNP十件，无3BA运行模型/BS/TRI/SMP适配 | PSQ内已有九部件3BA与物理增强，耳环保留原版；独立十件穿戴与轻甲属性保持 |
| 海伦娜 | 条目虽有CBBE/3BA BS工程，却缺少胸甲、手套、鞋等运行模型；无独立尾巴，翼附在胸衣 | 补齐3BA运行模型/TRI与BS；项圈保持独立；保留原有有翼/无翼胸衣与两种耳环；增加PSQ配套尾巴和可独立穿戴的翼，各有锻造/强化配方 |

海伦娜补充尾巴是PSQ既有复用DX尾巴，并非声称原作者原本提供。海伦娜PSQ独立翼原模型分区为32而装备记录槽位为45，本次适配模型修正为45；普通独立翼使用46，避免与原作项圈45、耳环43、角55冲突。原有有翼胸衣通过第二个32槽Addon带翼，不挤占项圈。原作物品现有属性保持，新配件参考原作角饰的配方；新配件的地面展示模型沿用原作角饰，非专用地面展示模型。

## BodySlide

游戏运行模型已提供，可先直接测试。重新Build时勾选“建立变形”，所有相关组使用相同身形：
- PSQ六件变身：PSQ External DX Adapter / PSQ External Helena Adapter / PSQ External Shinano Adapter。
- 独立DX：PSQ - DX 独立轻甲优化组（项目为PSQ DX Standalone）。
- 独立海伦娜：PSQ Helena Standalone（含有翼胸衣所需的AttachedWings，整组一起Build）。
- 独立信浓：原作(gui)SucubusSister Shinano组。

不要再批量选择会覆盖同一路径的原作旧CBBE工程。停用PSQ会同时停用这批增强，原作基础目录不会被修改。需要CBBE 3BA、匹配骨架与FSMP，变形还需现有RaceMenu/Body Change NG环境。独立WingFlight/OSYRN未改。
