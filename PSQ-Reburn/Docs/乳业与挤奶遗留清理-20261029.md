# 乳业与挤奶遗留清理

当前PSQ已没有运行中的Milk Mod Economy外部接口。本次清理此前停用后仍留在PSQ中的挤奶器、产奶效果、乳汁及奶酪物品、配方、音效和BodySlide项目，而不是删除独立的“天际乳业-Milk Mod Economy SE AIO”。

移除meshes/psq/milker、textures/psq/milker、sound/fx/psq/fxmilking、miker c的BS源及OSP，共21个文件。删除17份翻译中6个未使用的乳业标签。

中瓶精液药剂原先引用Milk.nif，因此先迁移到PSQ/SemenPotion/MediumBottle.nif及独立材质目录。瓶子几何、UV、原色和法线DDS保持原样，药剂效果、数值、关键字和使用脚本不改；修正该模型内旧cow_girl路径指向同一瓶子法线。FHU储量转入、消化和精液药剂功能不移除。

13条旧记录只保留FormID作为无功能占位：无名称、效果、模型、脚本绑定、可用配方或声音；挤奶器不占穿戴槽。解除两个旧任务中的乳汁／挤奶声音默认绑定。所有其他插件记录及硬前置保持。

旧存档载入后的既有退场流程会清除玩家身上的旧挤奶器、乳汁、奶酪与奶酪块，并撤销旧iNeed食物注册；不会清除精液药剂、FHU储量或其他个人物品。用于接住旧存档事件的无产出清理脚本和旧公共标识保留，避免因删除脚本类型或FormID破坏旧存档。旧奶酪效果回调改为自行结束，不再生成物品。

主脚本只替换一个遗留清理函数，其他505个函数原字节保留；菜单脚本不改。旧SexLab／P+编译通过，194项退场／重复调用检查通过。检查427个模型消费者，确认无指向删除目录的引用；中瓶药剂实际效果字段与原件一致。游戏运行仍待验证。

所有改动仅在PSQ目录，独立MME、FHU、飞行模组和MO2配置不修改。安装前备份被删除及被覆盖文件，保存在工作区。
