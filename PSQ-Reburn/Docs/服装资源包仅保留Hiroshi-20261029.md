# 服装资源包仅保留Hiroshi

“PSQ Reburn - 变身服装包”仅保留Hiroshi（当前Set08／X魅魔）的六部件模型、TRI、BS源、颜色材质及所需物理文件，共6个BS工程。龙之公主（Set03）、TERA 9DM（Set05）旧模型、变形和BS工程从资源包移除；此前移除的其他套装不恢复。Hiroshi文件保持原字节，不变更颜色和形状。

独立原作接入与六部分独立切换保留，其他模组目录不改动。部分贴图仍被PSQ本体及原作适配复用，已按当前生效内容在PSQ本体保留；清理不会让这些消费者丢失资源。服装包内不再保留其他套装目录。

原脚本及ESM的一些默认模型指向Set03／Set05，现统一改为Set08安全回退。缺少独立原作时仍不可新选对应套装，旧配置使用Set08临时模型。保留所有FormID与硬前置列表，仅更新60个ARMA默认模型记录和一个脚本函数；其他记录与505个主脚本函数、全部菜单函数保持原样。

检查451个保留NIF消费者、288个ESM模型引用和6个BS工程，确认被清理的依赖有存活来源；旧SexLab／P+编译通过，854项PEX指令回归通过。安装前备份核心更新及所有被删文件，备份放在工作区。游戏内运行尚待验证。

本单套资源包须配合本次修订的PSQ核心（v0.26 revision33或之后版本）；旧核心仍可能引用已移除的资源。
