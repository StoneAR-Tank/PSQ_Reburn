## PSQ 自身可修问题：补满阶段的数组类型错误

入场窗口内出现 **5 条 `Cannot cast from None to Float[]`、4 条 `Mismatched types ... ::temp2`**，最后 00:19:28 报 `[PSQ-REFILL] incomplete owner=144; deferred completion requested`。直接检查当前实际生效 `playersuccubusquestscript.pex`，声明与现存 PSC 一致：

- `CaptureTransformPoolCaps` 返回类型为 `Float[]`，创建三元素 Float 数组并返回。
- `RefillTransformAttributes` 的 `Caps` 和 `::temp2` 都是 `Float[]`。指令 29 为 `Cast ::temp2 None`，源自 `Float[] Caps = None`；随后指令 52 用同一 `::temp2` 接收上述函数返回值，对应报错 debug 行 13195。
- `TransformPoolCapsMatch` 指令 0 为 `Cast ::temp0 None`，该临时变量也是 `Float[]`。它来自 `Caps == None` 的比较，debug 行 14012，与日志完全吻合。

因此发现的是**当前生成指令中的 None→数组转换问题**，不是已证实的函数返回声明不一致。错误转换影响后续临时变量赋值是强关联推断；运行日志不能单独证明全部 32 秒都由它造成。修复应移除这些显式数组 None 转换，并保留三项上限一致性、操作归属及补满验证；同时重新计时末段。不能仅将其归咎旧存档。
