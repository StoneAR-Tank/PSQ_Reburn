# PSQ Reburn v0.26

2026-10-29 服装原作接入修订：DX、海伦娜、信浓、凤蝶深渊、SW吸血鬼、龙之公主、TERA 9DM及Harry TERA均支持安装对应独立原作后接入。所有套装维持六部分替换，兼容文件由PSQ提供。当前独立资源包名为“PSQ Reburn - 变身服装包”，仅保留Hiroshi（Set08／X魅魔）一套资源；其余服装需安装对应独立原作。详见Docs下原作接入记录。MCM内部版本151。

基于原 PSQ、已有汉化和八套服装整合继续修改，包含其他作者的服装、动作、贴图与代码，并非全部原创。沿用汉化并补译修正；进化纹样为AI辅助设计。保留随包许可及署名。

## 安装与升级

1. 结束互动、退出变身及飞行，在地面另存并备份，退出游戏。
2. 安装PSQ本体与所需原作，兼容文件由PSQ覆盖原作；按需保留独立“PSQ Reburn - 变身服装包”。停用旧完整PSQ条目及旧PSQ累积补丁。不要同时启用两个版本，也不要让旧脚本覆盖本包。保留前置及独立飞行模组。
3. 主插件仍为 `PSQ PlayerSuccubusQuest.esm`，名称和FormID不变。本包只有这一项游戏插件，不含测试ESP，不合并或改名为ESL。
4. Body Change NG原模组独立保留；让PSQ在MO2左侧拥有更高优先级，使PSQ提供 `BodyChangeNG.dll`（1.3.7.2／API2）。补丁仅在PSQ目录，不向其他mod复制文件。
5. 使用独立Wingflight汉化或OSYRN时，让所选飞行核心提供 `Wingflight.dll`，覆盖PSQ内的旧兼容桥。飞行使用其原生菜单和按键；PSQ专有等级／跳高控制在独立模式下不可用。不要把两个Wingflight DLL改名并同时加载。
6. 更新后重启游戏，检查兼容页、变身／退出、三项属性、能量感知及FHU消化。本次没有新增动作；已有环境无需仅因打包重跑Pandora。全新安装动作时按自身行为生成器要求处理。

## 前置与可选内容

- 基础：匹配游戏版本的SKSE64、SkyUI、PapyrusUtil、SexLab、Heels Sound。当前主插件硬依赖仅 Skyrim.esm、Heels Sound.esm、SexLab.esm；PSQ没有SexLabAroused.esm硬依赖。欲望后端及其所需前置按所选接口安装。
- 框架：旧SexLab SE 1.63或P+ 2.19.0二选一，不同时启用。欲望接口支持SLA兼容、SLO Aroused NG、OSL与已注册提供器，具体以后端实际版本为准。不同框架切换建议分开MO2配置和存档副本。
- 外观：RaceMenu、CBBE 3BA、XPMSSE、服装所需的CBPC／FSMP、BodySlide；动作需OAR，建议MFG Fix。能量感知／眷属眼睛等扩展需powerofthree's Papyrus Extender及其匹配前置。
- 身形切换：独立Body Change NG 1.3.7本体及其前置，PSQ内提供接口版DLL。身体与服装采用同一身体体系、Zeroed Sliders＋建立变形；RaceMenu设置 `iBodyMorphMode=0`。缺少接口会停用身形切换，不回退到旧PSQ算法。
- 按功能选装：SLSO、FHU、UIExtensions、EFF／NFF、iNeed、Mannaz、GT_SoftBody、TDF、Apropos2。BDOR Hairstyles／Tullius Eyes、Pei style horns及动态翅膀资源仍由各自原mod提供。
- 飞行：Wingflight本体、独立汉化、OSYRN及其全部前置均独立安装，本包不含完整飞行或动态翅膀mod。当前PSQ已退休旧Real Flying接入；旧Real Flying外挂不是本版必需前置。OSYRN如搭配Mage's Leap，按其要求选择animation-only，避免Gravity版。
- SLIF／SLIF NG用于外部模组自身功能；PSQ已删除自己的腹部、胸部膨胀及孕育泌乳玩法，只保留旧PSQ来源清理和FHU储量转入／消化。

## v0.26 包含的三项修复

招引菜单清理空项和重复对象，保持候选列表与计数同步；使用菜单打开时的对象映射，返回后重验对象状态。只有一个候选时也可继续招引。

结束回调在等待后和清理前核对场景编号、序号、回调代次及读档代次，避免P+复用线程编号时旧回调关闭或结算新场景。

P+快速模式按高潮计数差逐次补结算。计数从0跳到2会结算两次；重复计数不重复吸取。每次仍单独应用原有药剂门槛、能量限制、经验及延后伤害累计；普通模式保持按时间差吸取。新场景接管结算锁后，旧回调不能释放新锁。框架只提供当前接触信息时，补结算沿用该次读取的接触类型，无法重建较早姿势。

主插件、模型和接口DLL未变，无新增持久脚本变量。旧SexLab编译与P+交叉编译通过，最终PEX经离线回归检查；尚未进入游戏验收。请在互动、变身与飞行结束后使用地面存档副本升级。运行包不含源代码或构建日志。

安装包仅保留运行资源、BodySlide所需资源、安装说明、版本／完整性清单及第三方许可。源码、构建记录、开发排查文档、备份与临时测试补丁不随本包提供。BodyChangeNG接口版DLL及Wingflight旧兼容桥沿用现有内容；外部框架及完整飞行本体仍独立安装。


服装拆分范围、当前限制与原作接入计划见 `Docs/服装拆分与原作接入计划-20261027.md`。当前第六套已接入gui-SucubusSister Shinano原作，其他七套原作接入仍待实现。
